# Gas Well Production: полиномиальная регрессия, Ridge и Lasso

Прогноз добычи газа по параметрам скважины. Показывает, как растёт качество при увеличении степени полинома и как регуляризация борется с переобучением.

## Что сделано
- EDA и выбор признаков
- Полиномиальные признаки степеней 1-4
- Регуляризация Ridge и Lasso

## Результаты (тест)
| Модель | R² | RMSE |
| --- | --- | --- |
| Полином степени 1 | 0.9506 | 204.5 |
| Полином степени 2 | 0.9731 | 150.8 |
| Полином степени 3 | 0.9888 | 97.5 |
| Полином степени 4 | 0.9875 | 102.9 |
| Ridge | 0.9919 | |
| Lasso | 0.9918 | |

Степень 4 уже хуже степени 3 (признак переобучения), регуляризованные модели дают лучшее качество.

## Запуск
Откройте `practice.ipynb` в Jupyter (датасет Gas Well Production, подставьте свой путь к файлу). Зависимости: pandas, numpy, scikit-learn, matplotlib, seaborn.
